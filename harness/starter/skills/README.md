# AgentForge Skills

The organizer intentionally does not provide operator-optimization Skills.

Contestants are expected to design their own Skills or adapt suitable
Skills from public repositories.

All Skills used during the official autonomous run must already exist
inside the frozen submission package.

External Skills must record their source, revision, and license.

Skills may provide reusable knowledge, workflows, debugging methods,
tool-use instructions, and optimization methodology.

Skills must not contain prewritten final operator solutions or hard-coded
evaluation outputs.
